# WiDS-Global-Datathon-BTT_Riparian
This project focuses on predicting whether a wildfire will threaten an evacuation zone within 12, 24, 48, and 72 hours, using only data from the first 5 hours after ignition. 

Our goal is to give emergency responders rankings of urgency and probability estimates that are reliable to help them make informed decisions regarding resource deployment, warnings, and evacuations.

Dataset
- Provided by WatchDuty and WiDS
- Includes wildfire perimeter and early incident features
- Target: Survival probabilities at multiple time horizons: prob_12h, prob_24h, prob_48h, prob_72h
- Notes: Right-censored survival problem; some fires may not reach reach evacuation zones within 72h
